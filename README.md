# Travel Website
Адаптивный лендинг для туристического сервиса с формой бронирования билетов.
<img width="1584" height="902" alt="image" src="https://github.com/user-attachments/assets/8580ef69-15e2-4567-b630-889cfe9e80a4" />
Технологии
- HTML5
- SCSS (адаптивная верстка, grid/flex)
- JavaScript (валидация форм, календарь, аккордеон)
- Figma (работа с макетом)

  Функционал
- Адаптивная верстка (desktop / tablet / mobile)
- Форма поиска билетов
- Кастомный календарь на JS
- Выпадающее меню

- Склонируйте репозиторий, откройте index.html в браузере
